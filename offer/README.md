# Luna Repo Clinic

Fast, fixed-scope repository health audits for small software teams.

The offer covers repository hygiene, onboarding friction, CI reliability signals, dependency-management posture, and security process gaps. It is intentionally a triage review with evidence and a prioritized remediation roadmap—not a penetration test or security certification.

## Validation offer

- 48-hour target turnaround after access is provided
- one repository, one default branch, read-only inspection
- concise Markdown report with evidence, severity/priority, and next steps
- €149 pilot price; direct USDC settlement on Base is available as a manual payment route, with no hosted checkout or escrow
- no customer code is executed by the local scanner

## Trust and data boundaries

- Public repository and exact commit are preferred; never put credentials in the intake
- Repository code and workflows are not executed
- Findings remain private unless the customer approves publication
- Non-public access is accepted only after written scope and handling terms are agreed
